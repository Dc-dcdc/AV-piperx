# AVERT 论文配置记录（Phase 0）

更新日期：2026-08-10

## 已确认配置

- 目标会议：IEEE International Conference on Robotics and Automation（ICRA）
- 暂定英文标题：**AVERT: Role-Isolated Error Recovery and Trajectory Alignment for Robust Active Visual Manipulation**
- 论文类型：机器人学习方法论文，采用 IMRaD 主体结构
- 研究领域：主动视觉、模仿学习、扩散策略、双臂/多臂机器人操作、闭环恢复
- 核心研究问题：角色隔离干预与轨迹对齐恢复监督，能否使统一的主动视觉操作策略在视角或操作偏离后恢复，同时维持任务进程？
- 核心方法：共享视觉表征、角色特异的操作扩散分支与视角扩散分支、角色隔离干预、环境动力学闭环恢复采集、面向推进中名义轨迹的监督对齐、名义执行与恢复联合学习
- 目标平台：两条操作臂与一条主动视角臂构成的三臂平台
- 引用风格：IEEE 数字编号制
- 论文正文语言：英文
- 协作与阶段报告语言：简体中文
- 工作格式：Markdown + LaTeX
- 文献质量配置：`cs_ml`（允许正式会议论文与可核查的近期预印本；预印本必须明确标注）
- 引用核验：严格模式；优先使用论文原文和出版社、会议、作者项目页等一手来源
- ARS 运行模式：Full

## 暂定贡献表述

1. 提出面向主动视觉操作的角色隔离恢复数据构造方法：每次只扰动一个目标控制角色，其余角色继续执行时间同步的名义指令，从环境动力学闭环中采集由扰动引起的非生成式观测变化及恢复序列。
2. 提出恢复—任务轨迹对齐机制：受扰角色不回到静态历史锚点，而是对齐到持续推进的专家任务轨迹，以减少跨角色监督混杂并维持任务进程。
3. 在共享视觉表征上以角色特异扩散分支统一学习名义执行与闭环恢复，无需在线失败检测、人工接管或独立恢复策略。
4. 在三臂精密操作平台上系统评估视角偏移、操作扰动及二者组合条件下的恢复能力、闭环鲁棒性和任务成功率。

以上为待实验与消融支持的贡献假设，不作为已经证实的结论。
